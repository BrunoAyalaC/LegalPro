# /review-pr

Revisa un Pull Request con checklist de calidad.

## Uso

```
/review-pr <numero>
```

## Agente

`@reviser`

## Checklist

- SOLID, DRY, KISS, YAGNI
- Convenciones del repo
- Seguridad (OWASP)
- LPDP compliance
- Tests (unit + integration + e2e)
- Cobertura >= 80%
- Documentación actualizada
