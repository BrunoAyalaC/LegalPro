# /liquidar-cts

Calcula la CTS al cese según D.Leg. 650.

## Uso

```
/liquidar-cts <fecha_inicio> <fecha_fin> <remuneracion> <sistema_pension>
```

## Agente

`@contador-laboralista`

## Output

- Cálculo de CTS
- Tasa BCRP aplicada
- Aportes AFP/ONP
- EsSalud
- Total a pagar
