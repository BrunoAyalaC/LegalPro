# /buscar-jurisprudencia

Busca jurisprudencia vinculante en 5 fuentes peruanas.

## Uso

```
/buscar-jurisprudencia <query> [--fuente=PJ|TC|INDECOPI|SUNARP|MINJUS] [--max=10]
```

## Fuentes

- **PJ**: Casaciones y acuerdos plenarios
- **TC**: Sentencias del Tribunal Constitucional
- **INDECOPI**: Resoluciones
- **SUNARP**: precedentes registrales
- **MINJUS**: Normativa

## Agente

`@ia-buscador-jurisprudencia`

## Output

- Lista de sentencias/resoluciones
- Cita exacta (expediente, fecha, sala)
- Ratio decidendi vs obiter dicta
- Link a SPIJ
