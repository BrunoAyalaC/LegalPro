# /predecir-resultado

Predice resultado probabilístico de un caso judicial.

## Uso

```
/predecir-resultado <expediente_id> <materia>
```

## Agente

`@ia-predictor-judicial`

## Output

- Probabilidad favorable/desfavorable/incierto
- Nivel de confianza (BAJO, MEDIO, ALTO)
- Sentencias base del análisis
- **DISCLAIMER**: "Análisis probabilístico, no garantiza resultado"
