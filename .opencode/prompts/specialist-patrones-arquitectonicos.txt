## Patrón Decorator (Higher-Order Functions)

Implementación canónica: `legalpro-app/server/core/decorators.js`

### Compositor: `pipe(...decorators)(fn)`

```javascript
import { pipe, withLogging, withValidation, withRetry, withIdempotency } from '../core/decorators.js';

const safeCrearExpediente = pipe(
  withLogging('crearExpediente'),
  withValidation(expedienteSchema),
  withRetry({ retries: 2, shouldRetry: (e) => e.code === 'ETIMEDOUT' }),
  withIdempotency({ keyFn: (input) => `exp:${input.numero}`, windowMs: 600_000 }),
)(crearExpedienteHandler);
```

### Decoradores disponibles (8)

1. **`pipe(...decorators)`** — composición de izquierda a derecha
2. **`withLogging(name)`** — log estructurado entrada/salida con duración
3. **`withTiming(name)`** — métricas de duración ms
4. **`withRetry({retries, delayMs, backoff, shouldRetry})`** — reintentos selectivos
5. **`withValidation(schema)`** — Zod/FluentValidation pre-ejecución (devuelve Err)
6. **`withCircuitBreaker({failureThreshold, cooldownMs, name})`** — circuit breaker CLOSED→OPEN→HALF_OPEN
7. **`memoize({ttlMs, keyFn})`** — cache en memoria con TTL
8. **`withIdempotency({keyFn, windowMs})`** — dedupe por clave

## Patrón Observer + EventBus

Implementación canónica: `legalpro-app/server/core/EventBus.js`

```javascript
import { domainEvents } from '../core/EventBus.js';

// Suscriptor
domainEvents.on('expediente.creado', async (evt) => {
  await notificarAbogado(evt.payload);
}, { priority: 100 });

// Wildcard para auditoría global
domainEvents.on('*', async (evt) => {
  await auditLog.append({ type: evt.type, payload: evt.payload, meta: evt.meta });
}, { priority: 999 });

// Emisión
await domainEvents.emit('expediente.creado', { id, numero }, {
  orgId: req.tenantId,
  userId: req.user.id,
  correlationId: req.correlationId,
});
```

### Características

- Handlers sync y async
- Prioridad ascendente (menor = antes)
- `once()` para suscripciones de un solo uso
- Wildcard `*` para escucha global
- **Aislamiento de errores** (un suscriptor que lanza NO rompe a los demás)
- Outbox opcional para transactional outbox

## Patrón Adapter (Port & Adapter / Hexagonal)

Implementación canónica: `legalpro-app/server/adapters/`

### Contrato canónico

```typescript
interface Adapter<TInput, TOutput> {
  readonly name: string;
  readonly version: string;
  readonly baseURL: string;
  readonly timeoutMs: number;
  readonly cacheTTL?: number;
  execute(operation: string, input: TInput): Promise<AdapterResult<TOutput>>;
  healthCheck(): Promise<boolean>;
}
```

- SOLID estricto

- Dependency Inversion: Domain depende de puertos (interfaces), no de adapters concretos
