## Técnicas de optimización

### 1. Hybrid Search (BM25 + Vector)

Para términos técnicos legales densos, combinar búsqueda por keywords (BM25/tsvector) con búsqueda vectorial (embeddings).

```sql
-- Índice full-text en español
CREATE INDEX idx_normas_search ON codigos_leyes
  USING GIN (to_tsvector('spanish', nombre || ' ' || observaciones));
```

### 2. Re-ranking con cross-encoder

Después del retrieval inicial, aplicar cross-encoder para re-rankear top-K.

### 3. Metadata filtering ANTES del retrieval

Filtrar por `materia` (penal/civil/laboral) ANTES de la búsqueda vectorial.

### 4. Chunking por secciones semánticas

Cada chunk debe ser autocontenido (artículo completo + contexto).

### 5. Citation strip

Cada chunk debe incluir URL SPIJ para verificación humana.

### 6. Caching de embeddings

Cachear embeddings de queries frecuentes en Redis.

## Métricas RAG obligatorias

| Métrica | Target | Cómo medir |
|---|---|---|
| Retrieval precision @ K | ≥ 0.85 | Eval-set manual de 50 casos |
| Retrieval recall @ K | ≥ 0.90 | Eval-set con Ground Truth |
| Citation accuracy | ≥ 0.98 | % de citas con [N] válido |
| Hallucination rate | < 0.02 | Detección con regex + LLM eval |
| Context relevance | ≥ 0.80 | LLM evalúa relevancia del contexto |
| Answer relevance | ≥ 0.85 | LLM evalúa relevancia de respuesta |
| Latencia p95 con RAG | < 3s | APM |
| Costo/req | < $0.10 | tracking `consumo_tokens_ia` |

## Anti-alucinaciones

1. **Validación de citaciones**: regex `\[\d+\]` debe coincidir con índice de fuente
2. **Detección de patrones sospechosos**: leyes inventadas, artículos mal formados
3. **Post-procesamiento**: eliminar frases sin cita válida
4. **Disclaimers obligatorios**: 4+ por respuesta legal
5. **Limitar temperatura**: 0.0-0.3 para legal (determinismo)
6. **Function calling forzado**: `mode: ANY` para tareas críticas

## Hybrid RAG + Function Calling

```javascript
const systemInstruction = `
Eres un asistente jurídico especializado en el ordenamiento peruano.
Basa tu respuesta EXCLUSIVAMENTE en el contexto normativo proporcionado.
Cita las fuentes con el formato [N] donde N es el número de fuente.
NUNCA inventes artículos o leyes.
Idioma: es-PE.
`;

const tools = [{
  functionDeclarations: [
    loadFn('buscar_jurisprudencia'),
    loadFn('calcular_plazos'),
    loadFn('validar_cita_legal'),
    loadFn('obtener_tipo_penal'),
  ],
}];

const response = await ai.chat.completions.create({
  model: 'MiniMax-M3',
  temperature: 0.1,
  messages: [
    { role: 'system', content: systemInstruction },
    { role: 'user', content: promptAugmented },
  ],
  tools,
  tool_config: { function_calling_config: { mode: 'ANY' } },
});
```
